# **LLD + HLD Interview Preparation Roadmap**

Follow this order. No random tutorials, no unnecessary topics.

## **1. LLD — Low-Level Design**

**A. OOP fundamentals**

- Encapsulation, Abstraction, Inheritance, Polymorphism
- Composition vs Inheritance
- Association, Aggregation, Composition
- Interface vs Abstract Class

**B. SOLID Principles**

- SRP
- OCP
- LSP
- ISP
- DIP

**C. Design Patterns**

- Strategy
- Factory
- Observer
- State
- Decorator
- Singleton
- Builder
- Adapter

**D. Java for LLD**

- Collections (List, Set, Map, Queue)
- equals() and hashCode()
- Enums
- Generics
- Immutability
- Exception handling
- Dependency Injection

**E. Multithreading**

- Race conditions
- synchronized
- volatile
- Locks
- Atomic variables
- ConcurrentHashMap
- ExecutorService
- Deadlocks

**F. Practise these LLD problems**

1. Parking Lot
2. Elevator System
3. Splitwise
4. Library Management System

## **2. HLD — High-Level Design**

**A. Fundamentals**

- Functional vs Non-functional requirements
- Availability, Scalability, Reliability
- Latency and Throughput
- CAP theorem
- Consistency models
- Basic capacity estimation (QPS, storage, bandwidth)

**B. Architecture Components**

- DNS
- CDN
- Load Balancer
- API Gateway
- Reverse Proxy
- Application Servers
- Stateless vs Stateful architecture

**C. Database**

- SQL vs NoSQL
- Indexing
- Query optimization
- Transactions and ACID
- Replication
- Read Replicas
- Sharding
- Partitioning
- Connection Pooling

**D. Caching**

- Redis
- Cache-aside
- Write-through
- Write-behind
- TTL
- LRU / LFU
- Cache Invalidation
- Cache Stampede
- Consistent Hashing

**E. Messaging**

- Synchronous vs Asynchronous
- Message Queues
- Kafka basics
- Producer / Consumer
- Consumer Groups
- Retries
- Dead Letter Queue
- Idempotency
- Eventual Consistency

**F. Scalability & Reliability**

- Vertical vs Horizontal Scaling
- Rate Limiting
- Load Balancing Algorithms
- Failover
- Circuit Breaker
- Retry and Timeout
- Health Checks
- Monitoring and Logging

**G. Practise these HLD problems**

1. URL Shortener
2. Notification System
3. File Storage System
4. E-commerce Product Catalog
5. WhatsApp / Chat System
